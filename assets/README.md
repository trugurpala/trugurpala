# Profile assets

These files are exported from the [Uğur Pala Social Kit](https://www.figma.com/design/YCvTtkpouNHKU2OEghpFGp).

| File | Size | Use |
| --- | --- | --- |
| `github-avatar-500.png` | 500×500 | GitHub profile avatar |
| `github-profile-banner.png` | 1200×320 | Profile README banner |
| `x-header.png` | 1500×500 | X profile header |
| `divan-social-preview.png` | 1280×640 | Divan social preview |
| `delivery-process.png` | 1200×260 | Divan delivery-process strip |

The source of truth is the Figma file, on the `01 — Export Assets` page. Keep the exported dimensions and filenames stable when replacing an asset.

GitHub-facing exports follow GitHub's official [profile picture requirements](https://docs.github.com/en/account-and-profile/reference/profile-reference#profile-picture-requirements) and [social preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview): descriptive image alt text, relative repository paths, a roughly 500×500 avatar, and a 1280×640 social preview under 1 MB. Use solid backgrounds so previews remain legible across light and dark surfaces.
