# Katkıda Bulunma

Bu depo, Uğur Pala'nın GitHub profil sayfasını içerir. Bir proje hatası veya
özellik önerisi için lütfen ilgili projenin kendi deposunu kullanın.

## Doğru yolu seçin

- Profildeki yanlış veya eksik bilgi için
  [hata bildirimi](https://github.com/trugurpala/trugurpala/issues/new?template=bug_report.yml)
  açın.
- Profilin daha anlaşılır olması için
  [iyileştirme önerisi](https://github.com/trugurpala/trugurpala/issues/new?template=feature_request.yml)
  gönderin.
- Güvenlik açığını herkese açık issue veya pull request içinde paylaşmayın;
  [güvenlik politikasındaki özel yolu](SECURITY.md) kullanın.
- Bir ürünle ilgili kullanım sorusu, hata veya öneri için ürünün kendi
  deposundaki `SUPPORT.md` ve issue şablonlarını izleyin.

## Değişiklik gönderin

1. Depoyu fork edin ve açıklayıcı bir dal oluşturun.
2. Profil metnini kısa, somut ve son kullanıcıya dönük tutun.
3. Bir proje hakkında kanıtlanmayan hız, kalite veya başarı iddiası eklemeyin.
4. Bağlantıları ve Markdown görünümünü kontrol edin.
5. Pull request içinde neyin değiştiğini ve nedenini açıklayın.

Katılımınız [Davranış Kuralları](CODE_OF_CONDUCT.md) kapsamındadır.
