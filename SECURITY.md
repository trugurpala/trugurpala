# Güvenlik Politikası

## Özel bildirim yapın

Bir güvenlik açığı bulduysanız
[GitHub Security Advisory üzerinden özel bildirim](https://github.com/trugurpala/trugurpala/security/advisories/new)
gönderin. Güvenlik ayrıntılarını herkese açık issue, discussion veya pull
request içinde paylaşmayın.

Bildirimde şunları ekleyin:

- Etkilenen depo, sürüm veya commit
- Olası etki
- Kişisel ve gizli verileri çıkarılmış en küçük güvenli tekrar üretim
- Biliniyorsa geçici çözüm

Token, parola, özel anahtar, müşteri verisi, gerçek finansal veri, özel depo
bağlantısı veya kişisel bilgisayar yolu göndermeyin.

## Kapsam

Bu profil deposu yalnız profil belgelerini ve görsel varlıkları içerir. Başka
bir açık projedeki güvenlik sorunu için o projenin `SECURITY.md` dosyasındaki
özel bildirim yolunu kullanın.

İlk yanıt için hedef süre 72 saattir. Düzeltme ve açıklama zamanı; etkinin
ciddiyetine, tekrar üretilebilirliğe ve diğer projelerle gerekli eş güdüme
bağlıdır.
