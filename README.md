### Merhaba, ben Uğur.

Python ve Pine Script ile fikirleri çalışan araçlara dönüştürüyorum. Şimdilerde odağım, Claude Code ve Codex için geliştirdiğim açık kaynak [Divan](https://github.com/trugurpala/divan).

Divan, Claude Code veya Codex ile yürüttüğün işi düzenli bir sürece oturtuyor. Önce ne yapılacağını netleştiriyor, ardından işi planlıyor ve kontrolleri çalıştırıyor. Sonucu da kanıtlarıyla birlikte teslim ediyor.

Bir yandan [Pine Script Agent Kit](https://github.com/trugurpala/pinescriptv6) üzerinde çalışıyorum. Bu açık kaynak bilgi paketi, yapay zekâ kodlama araçlarının Pine Script v6 yanıtlarını adı belli kaynaklara dayandırmasına yardımcı oluyor. Yerel kontrollerin neyi kanıtlayıp neyi kanıtlamadığını da açıkça gösteriyor.

Türkiye IBAN ekosisteminde de [veri temelini](https://github.com/trugurpala/turkiye-iban), [PHP istemcisini](https://github.com/trugurpala/turkiye-iban-php) ve [Python istemcisini](https://github.com/trugurpala/turkiye-iban-python) yayımlıyorum. Bu projeler IBAN biçimi ile kuruluş kodu eşleştirmesini açıkça sınırlar; bir hesabın gerçekten var olduğunu iddia etmez.

Divan v1.3 serisinde. Denersen nelerin işe yaradığını, nerelerde takıldığını duymak isterim.
