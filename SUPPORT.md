# Destek

Bu depo Uğur Pala'nın GitHub profil sayfasını içerir; ürün desteği sunmaz.

| İhtiyaç | Yol |
|---|---|
| Profilde yanlış veya eksik bilgi | [Hata bildirimi](https://github.com/trugurpala/trugurpala/issues/new?template=bug_report.yml) |
| Profil için iyileştirme önerisi | [Özellik önerisi](https://github.com/trugurpala/trugurpala/issues/new?template=feature_request.yml) |
| Bir projeyi kullanma, hata veya katkı | İlgili projenin README ve `SUPPORT.md` dosyası |
| Güvenlik açığı | [Özel güvenlik bildirimi](https://github.com/trugurpala/trugurpala/security/advisories/new) |
| Özel iletişim | [mail@ugurpala.com](mailto:mail@ugurpala.com) |

Issue açmadan önce doğru projede olduğunuzu kontrol edin. Herkese açık
bildirimlerden token, e-posta, gerçek finansal veri, müşteri verisi, özel depo
bağlantısı ve kişisel bilgisayar yollarını çıkarın.
